# Игра 2048

Интерактивное веб-приложение, реализованное на нативном TypeScript с использованием сборщика Vite.

## Описание
Классическая игра 2048. Поле 4x4. Управление стрелками клавиатуры (или WASD). Одинаковые плитки сливаются, очки суммируются. Рекорд сохраняется в localStorage.

## Технологии
* TypeScript
* Vite
* Jest (юнит-тесты)
* ESLint

## Запуск
1. Установите зависимости: `npm install`
2. Запустите dev-сервер: `npm run dev`
3. Откройте в браузере: `http://localhost:5173`

## Тестирование
Запуск тестов: `npm run test`
